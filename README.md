# 💻 Sistema de Chamados — Help Desk

Sistema web desenvolvido como projeto de estudo para simular o gerenciamento de solicitações de suporte técnico.

O projeto permite registrar chamados, definir prioridades, acompanhar solicitações e atualizar seus status. Os dados são armazenados no navegador por meio do LocalStorage.

## 🚀 Funcionalidades

- Cadastro de chamados
- Definição de prioridade: baixa, média e alta
- Listagem das solicitações registradas
- Atualização do status dos chamados:
  - Aberto
  - Em andamento
  - Resolvido
- Armazenamento dos dados no navegador com LocalStorage

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Utilize a interface para testar as funcionalidades disponíveis.

Não é necessário configurar um servidor Node.js para a versão atual do projeto.

## 🧪 Testes manuais

O funcionamento pode ser verificado por meio dos seguintes testes:

- Criar um chamado e conferir se aparece na listagem.
- Definir uma prioridade e verificar se ela é exibida corretamente.
- Alterar o status de um chamado.
- Atualizar a página e verificar se os dados continuam salvos no navegador.
